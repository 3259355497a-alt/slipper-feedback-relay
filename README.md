# 拖鞋战神反馈备用入口（待部署）

只将匿名提交凭证、反馈提交和公开版本查询转发至现有反馈服务。数据库与管理员后台仍在原站点；这里没有反馈列表接口，不复制管理员身份或密码，不记录反馈正文。

部署候选：Vercel Functions，个人非商业 Hobby 免费方案。尚未部署，也未证明手机或国内各运营商可用；必须在真实部署后测试。超过免费配额会受限，不能保证永久免费或全网络可达。

上线前需要用户亲自登录/注册 Vercel、确认协议与所需 GitHub 授权，并同意玩家编号、昵称、版本和反馈正文由该服务处理后转发。不得将客户端或私密签名文件上传至此工程。

仅公开三个接口：`POST /api/ticket`、`POST /api/feedback`、`GET /api/version`。反馈成功必须有原服务的持久化回执；失败返回错误，不伪造成功。请求限14KB，固定目标、超时8秒、禁止重定向、剔除额外字段及所有身份凭证。保留原服务的身份校验、幂等去重与频率限制。原服务按IP的频率限制会同时作用于共享出口用户；大量玩家使用前需进一步容量评估。

通过本地测试后仍须做真实匿名提交和数据库回读，最后发布同签名新APK并同步官网、镜像、版本接口。现有v1.0.8不会自动改用这个入口。原始反馈内容仍保留在玩家本机草稿，不能宣称已自动补传。
